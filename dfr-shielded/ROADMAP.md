# Roadmap

1. Validate upstream DFR XFRM/strongSwan endpoint semantics.
2. Implement QUIC/TLS 1.3 datagram carrier as a sidecar.
3. Add authenticated token/channel binding and replay-resistant session establishment.
4. Add MTU discovery and bounded padding.
5. Integrate carrier lifecycle with DFR health/recovery.
6. Add native/shielded fallback.
7. Benchmark video, iperf3, reconnect, and multi-user load.
